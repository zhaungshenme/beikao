# 备考

单人、本机使用的学习与练习网站，提供顺序练习、随机练习、模拟考试、错题复盘、收藏、笔记、题目讲解与可选的网页资料检索。使用 Vue 3、TypeScript、Element Plus 与 Node.js 本地服务。

**公开版本附带 2000 道原创模拟题、题库原解析及按题保存的通用讲解。** 安装后可直接练习和阅读讲解，不需要 API Key，也不需要浏览器插件。个人学习记录、笔记和密钥不随仓库发布。

## 快速开始

1. 安装 [Node.js 当前 LTS](https://nodejs.org/)，建议使用 Node.js 22 LTS 或更新的 LTS，并确认包含 npm。
2. 解压项目，在含 `package.json` 的目录打开终端，执行 `npm ci`。
3. Windows 双击 **`启动备考.cmd`**，等待构建并自动打开网站。使用结束后双击 **`停止备考.cmd`**；关闭浏览器不会停止后台服务。

默认地址为 <http://127.0.0.1:18103/study/>。关机后需重新启动服务。macOS/Linux 或希望前台运行时执行：

```sh
npm run build:study
npm run study
```

终端运行方式用 Ctrl+C 停止。无需另行部署管理系统后端或数据库。

## 导入自己的题库

先停止网站，在项目根目录执行：

```sh
node study/import-bank.mjs "你的题库.json" --check
node study/import-bank.mjs "你的题库.json"
```

导入成功后重新启动网站。工具将题库写入本机 `study/data/questions.json`；默认拒绝覆盖已有题库。确需替换时使用 `--replace`，原题库会先备份。字段结构、替换注意事项见 [题库导入说明](study/README.md#题库导入)。项目已内置 2000 道模拟题；替换内置题库时需显式使用 `--replace`。与新题库版本不匹配的内置讲解会自动停用。

## 题目讲解与可选网页资料

题库原解析和此前已保存的通用讲解可直接阅读。需要补充公开资料时，在学习设置中填写自己的 DeepSeek 开放平台 API Key；服务地址固定，仅调用官方 Search／Fetch，保存来源与返回的网页正文或文档摘录，不调用生成模型。PDF 只保留 Search 返回的文字摘录，不调用 Fetch，也不作为全文展示。

只有主动检索才会发送当前题目的检索信息；不发送个人作答、追问、笔记或学习记录。资料按题目版本保存在本机，已有记录直接读取，失败或结果未知不会自动重试。工具可能计费，以服务商账单为准；保存配置、浏览题目和读取已存资料不会发起检索。无需网页助手或模型聊天网页，详见 [网页资料与历史说明](study/README.md#网页资料检索与解析历史)。

## 使用边界与数据

服务只供当前电脑上的单人使用，默认只监听 `127.0.0.1`，没有多账号权限隔离，**不适合直接部署到公网**。源码公开不意味着要公开个人服务或数据。

个人学习记录、笔记、模型配置和密钥保存在本机私人数据目录，默认是 `study/storage/`。仓库仅公开本项目随附的题库与通用讲解；不要提交自己替换后的私人题库、该目录或自定义私人数据目录。备份或迁移前先停止服务。完整启动、端口设置、数据管理和故障排查见 [使用说明](study/README.md)。

## 开发与源码发布

```sh
npm run verify:study
npm run release:source
```

第一条命令核验公开文件范围，再运行使用合成临时数据的测试、类型检查与构建，不调用在线模型。第二条生成供分享的源码包；只有明确列入白名单的 `study/data/questions.json` 和 `study/data/prepared-explanations.json` 随源码导出；两者须逐题匹配，且不允许夹带未知字段。其他题库、个人数据、密钥、检索原文、截图、旧扩展及原仓库 `.git` 不进入公开包。发布前检查生成结果，重新下载或解压到新目录验证安装启动。详细边界见 [数据与发布](study/README.md#数据与发布)。
