# 备考

单人、本机使用的学习与练习网站，提供顺序练习、随机练习、模拟考试、错题复盘、收藏、笔记和可选的 AI 解析。使用 Vue 3、TypeScript、Element Plus 与 Node.js 本地服务。

**公开版本只提供项目源码，不附带题目、题库解析或个人学习数据。** 首次启动显示空题库，请自行导入有权使用的题库。基础学习不需要模型账号，也不需要安装浏览器插件。

## 快速开始

1. 安装 [Node.js 当前 LTS](https://nodejs.org/)，建议使用 Node.js 22 LTS 或更新的 LTS，并确认包含 npm。
2. 解压项目，在含 `package.json` 的目录打开终端，执行 `npm ci`。
3. Windows 双击 **`启动备考.cmd`**，等待构建并自动打开网站。使用结束后双击 **`停止备考.cmd`**；关闭浏览器不会停止后台服务。

默认地址为 <http://127.0.0.1:18103/study/>。关机后需重新启动服务。macOS/Linux 或希望前台运行时执行：

```sh
npm run build:study
npm run study
```

终端运行方式用 Ctrl+C 停止。无需另行部署管理系统后端或数据库。

## 导入自己的题库

先停止网站，在项目根目录执行：

```sh
node study/import-bank.mjs "你的题库.json" --check
node study/import-bank.mjs "你的题库.json"
```

导入成功后重新启动网站。工具将题库写入本机 `study/data/questions.json`；默认拒绝覆盖已有题库。确需替换时使用 `--replace`，原题库会先备份。字段结构、替换注意事项见 [题库导入说明](study/README.md#题库导入)。项目不提供题目示例或默认题目内容。

## 可选 AI 解析

在学习设置中填写自己的模型服务地址、模型 ID 和 API Key，支持 OpenAI Chat Completions 兼容 API。DeepSeek 官方服务还可选择 Search／Fetch 联网检索，再结合当前题目、作答与追问生成解析。

AI 与联网检索会将相应内容发送给服务商，并可能计费。检索默认关闭；保存配置、打开页面和基础练习不会调用模型。无需网页助手或模型聊天网页。费用、发送内容与失败恢复说明见 [AI 解析说明](study/README.md#ai-解析与官方检索)。

## 使用边界与数据

服务只供当前电脑上的单人使用，默认只监听 `127.0.0.1`，没有多账号权限隔离，**不适合直接部署到公网**。源码公开不意味着要公开个人服务或数据。

个人学习记录、笔记、模型配置和密钥保存在本机私人数据目录，默认是 `study/storage/`。不要把自己的题库、该目录或自定义私人数据目录上传到仓库。备份或迁移前先停止服务。完整启动、端口设置、数据管理和故障排查见 [使用说明](study/README.md)。

## 开发与源码发布

```sh
npm run verify:study
npm run release:source
```

第一条命令运行隔离测试、类型检查与构建，不要求附带真实题库，也不调用在线模型。第二条生成供分享的源码包；题库内容、个人数据、密钥、历史原文、截图、旧扩展及原仓库 `.git` 不进入公开包。发布前检查生成结果，重新下载或解压到新目录验证安装启动。详细边界见 [数据与发布](study/README.md#数据与发布)。
