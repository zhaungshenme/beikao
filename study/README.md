# 备考本机学习平台

这是单人、本机使用的题库与练习平台。公开版本附带 2000 道原创模拟题、原解析和通用讲解，不包含个人学习数据。安装后即可开始练习；基础刷题、判分、笔记与复盘不需要模型账号或 API Key。

## Windows 日常打开网站

在项目的 `package.json` 所在文件夹，双击 **`启动备考.cmd`**。等待构建完成后，会自动打开学习网站；已经启动时会使用现有服务。结束使用时双击同一文件夹的 **`停止备考.cmd`**，学习记录会保留。

默认学习网站是 <http://127.0.0.1:18103/study/>。`127.0.0.1` 指的是正在使用的这台电脑。关机后服务也会停止，下次先双击启动入口，再访问网址。关闭浏览器不会停止后台服务。

如果浏览器显示“拒绝连接”，先双击启动入口。启动失败时窗口会保留原因；不要只反复刷新浏览器。启动入口无需管理员权限，不修改系统执行策略；仅为本次 PowerShell 子进程允许执行项目脚本。它不会安装依赖或调用模型。

## 首次准备（只需一次）

1. 从 <https://nodejs.org/> 安装当前 Node.js LTS，建议使用 Node.js 22 LTS 或更新的 LTS，并确认包含 npm。项目最低要求 Node.js 20.19+，使用 22 系列时需 22.12+；建议 npm 9+。
2. 将下载的项目完整解压。打开含有 `package.json`、`启动备考.cmd` 的文件夹，在文件资源管理器地址栏输入 `cmd` 并按回车。
3. 在弹出的窗口输入 `npm ci` 并按回车，等待依赖安装结束。此步骤会下载项目依赖；失败时查看错误，不要继续启动。
4. 关闭该窗口，以后双击 `启动备考.cmd` 即可使用。首次启动即可使用内置 2000 题；若要更换题库，导入步骤见下文。基础刷题不需要安装网页助手，也不需要 API Key。

更新项目源码后，先双击停止入口，再双击启动入口，启动时会构建当前版本；不会自动下载更新。启动失败时，可将窗口中的错误信息提供给维护者。

## 终端启动（可选）

完成首次准备后，在本项目 `package.json` 所在目录执行：

```sh
npm run build:study
npm run study
```

打开终端打印的地址，默认是 <http://127.0.0.1:18103/study/>。终端运行方式用 Ctrl+C 停止。首次启动自动建立独立数据目录；干净安装不会自动开始批量生成或发起模型请求。

Windows 也可直接使用 `./Start-Study.ps1` 后台启动、`./Stop-Study.ps1` 停止。PowerShell 脚本每次启动先构建；从 PATH 查找 Node，可用 `-NodePath '完整的 node.exe 路径'` 指定。直接调用这两个脚本不会打开浏览器。双击入口支持同样的 `-NodePath` 参数；终端调用 `启动备考.cmd -NoBrowser` 可只启动、不打开网页。

## 题库导入

公开包包含 `study/data/questions.json` 的 2000 题及 `study/data/prepared-explanations.json` 的通用讲解。题库原解析与通用讲解分别保留，讲解按完整题目指纹匹配；题干、选项、标准答案或原解析变化时，旧讲解不会错配显示。本机已有匹配讲解优先使用，内置讲解只读，不写入学习记录。缺少题库文件时仍可空题库启动。若要更换题库，请准备 UTF-8 编码的 JSON 文件，顶层为题目数组。先停止服务，再在项目根目录执行：

```sh
node study/import-bank.mjs "你的题库.json" --check
node study/import-bank.mjs "你的题库.json"
```

`--check` 只校验，不写入。实际导入将内容写入 `study/data/questions.json`，默认拒绝覆盖任何已有题库。需要替换时显式执行 `node study/import-bank.mjs "你的题库.json" --replace`；原题库会先保存到当前私人数据目录的 `backups/question-bank-*.json`。导入后重新启动服务，网页才会读取新题库。服务运行时导入会被写入锁阻止。

每个题目对象的字段如下；字段说明如下：

| 字段 | 类型与约束 |
| --- | --- |
| `id` | 唯一、非空字符串，最多 100 字符；不能包含控制字符，不能为 `__proto__`、`constructor` 或 `prototype`。 |
| `category`、`chapter`、`knowledgePoint` | 科目、章节、知识点，均为非空字符串，每项最多 200 字符。 |
| `type` | `single` 表示单选，`multiple` 表示多选。 |
| `difficulty` | 难度非空字符串，最多 200 字符，可使用自己的难度名称。 |
| `stem` | 非空题干字符串，最多 10000 字符。 |
| `options` | 2～26 个选项对象组成的数组；每项含唯一非空 `id` 与非空 `text`，选项文本最多 10000 字符。选项编号不限于 A～D。 |
| `answer` | 不重复的选项编号数组，必须引用当前题目中的选项；至少一个答案，单选须恰好一个。 |
| `explanation` | 解析字符串，可为空，最多 20000 字符。 |
| `source` | 可选的来源字符串，最多 1000 字符，用于标明内容出处。 |
| `referenceUrls` | 可选参考链接数组，最多 20 条，每条最多 2048 字符；须为不含账号密码的 HTTPS 链接。 |

导入文件最多 32 MiB、50000 题。校验检查格式与引用关系，不保证答案及解析的事实正确，也不检查题库的内容授权。为避免错配已有学习记录，同一道题应保持稳定 `id`，不同题目不要复用旧题号；替换题库前先备份私人数据。

## 配置

配置通过当前进程环境变量传给 Node，启动与停止时需使用相同配置：

| 变量 | 默认值 | 含义 |
| --- | --- | --- |
| `STUDY_PORT` | `18103` | 1～65535 的监听端口 |
| `STUDY_HOST` | `127.0.0.1` | 只支持 `127.0.0.1` 或 `localhost` |
| `STUDY_DATA_DIR` | `study/storage` | 数据目录；相对路径始终相对项目根目录 |

数据目录不能位于 `study-dist/`、`study/data/` 或 `study/bridge/`，避免与构建输出、本机题库和网页资源混用。默认与示例数据目录已经加入 Git 忽略；使用其他自定义目录时，请将其加入自己的 `.git/info/exclude`。

PowerShell 示例：

```powershell
$env:STUDY_PORT = '18104'
$env:STUDY_DATA_DIR = 'local-data/my-study'
./Start-Study.ps1
# 在同一配置下停止
./Stop-Study.ps1
```

macOS/Linux 前台示例：`STUDY_PORT=18104 STUDY_DATA_DIR=local-data/my-study npm run study`。只启动一个实例写入一个数据目录。

当前不支持公网部署、手机远程访问或多账号权限隔离。不要将服务反向代理到公网；本机检查不替代用户认证。

## 网页资料检索与解析历史

在学习设置中填写自己的 DeepSeek 开放平台 API Key。服务地址固定为官方 `https://api.deepseek.com/v1/tools/search` 与 `/v1/tools/fetch`，不能切换到生成模型或第三方网关，不需要填写模型 ID，也不需要网页助手。密钥只保存在本机私人数据目录，不返回浏览器、不随学习导出或源码发布。网页账号与开放平台 API 的额度和计费相互独立。

点击题目页的“检索网页并保存”后，服务从当前题干、科目和知识点构造搜索词，仅调用官方 Search／Fetch，保存来源网址与返回文字，不生成、改写或事实核验解析。不发送个人作答、追问、笔记或学习记录。HTML 网页可通过 Fetch 读取正文；PDF 直接保留 Search 已返回的文档文字摘录，不调用 Fetch，不将摘录冒充完整文档。最多保留两份唯一来源，二进制内容不会作为文字资料接收。

每个题目版本最多主动检索一次，最多 1 次 Search 与 2 次 Fetch。Search／Fetch 可能计费，实际以服务商账单为准，不保证免费；失败前已经执行的工具调用也可能计费。单次工具请求等待最多 10 秒，检索合计最多 25 秒，响应大小上限为 256 KiB。保存配置、打开页面和读取已存资料都不会发起检索；项目不会自动循环、批量检索或切换到模型生成。

网页资料按题号、题目指纹和标准版本独立归档；在“查看已保存网页资料（只读）”中可以回看来源、正文或摘录、调用次数与状态。已有当前版本记录时直接读取，不再次检索；旧版本原文保留并标明版本差异。缺少来源或正文时如实显示失败或缺口，不把网页原文当作已核验答案，也不覆盖题库原解析或已保存的通用讲解。

失败、处理中或结果未知的同一版本不会自动重发。刷新与“读取检索记录”只查询本机归档；连接中断后先确认已保存状态，不能把未确认结果当作未执行。部分旧失败记录若已保存 PDF 的 Search 文字，会显示由原档案派生的本机恢复摘录；恢复不联网、不修改原失败终态、正文或调用次数，保留父档案与其哈希供核对。

升级前的个人 AI 解析、旧正文与终态记录继续保留。“查看本题解析历史”只读取本机历史，不调用生成模型；缺失的生成时间、当时选择或版本会标为未记录，归档时间不会冒充生成时间。学习备份导出与导入继续保留个人解析历史，冲突内容保留两份，重复导入不会重复新增。网页资料另存于私人数据目录的独立归档，完整迁移时应在停止服务后备份整个数据目录。

旧 `/ai/explain` 生成入口返回已停用状态（HTTP 410）；不会将检索结果再交给模型生成个人讲解。题目原解析和已有通用讲解仍可直接阅读；通用缓存的身份与答案匹配仅表示版本一致，不能当作事实审定。

旧网页版个人派发和批量派发已停用，旧 `/bridge/` 安装页与脚本返回已退役状态；不需要安装网页插件。已有本机历史缓存与终态记录不会因整理源码而删除，但不进入公开包。旧协议代码仅用于历史兼容和隔离回归，不再作为网站入口。

## 数据与发布

使用者下载并启动自己的备考、导入自己的题库后，即可阅读题库解析；如需网页资料，在学习设置填写自己的 DeepSeek 开放平台密钥，再主动检索。无需安装扩展，也不需要发布者的电脑保持开机。旧扩展源码与发布准备材料仅在原开发目录保留为历史资料，不随公开包分发。发布源码与向公网开放本机服务是两件事，当前服务仍限本机使用。

`study/data/questions.json` 是本项目公开的 2000 题，`study/data/prepared-explanations.json` 是与题目版本逐项匹配的通用讲解。只有这两个 JSON 进入公开包；其他自备题库、CSV、归档、网页原文和生成过程文件仍应保留在本机。缺少题库文件时仍可空题库启动。默认 `study/storage/` 是私人学习数据，包含学习记录、笔记、历史、可选模型配置与服务运行信息；不作为静态资源提供，也不应提交到 Git。自定义数据目录同样属于私人数据。可通过页面导出学习备份，完整迁移或目录备份应先停止服务。不要把第三方服务密钥放到源码或聊天中。

执行 `npm run release:source` 生成专门的源码目录和 ZIP，输出在 `artifacts/` 内，包含逐文件 SHA-256 清单 `RELEASE-MANIFEST.json`。公开包包含运行与开发所需源码、锁文件、文档、许可，以及明确列入白名单的两份题目与讲解数据；发布器拒绝未知题目字段、私人缓存字段、讲解指纹或标准答案错配。不包含个人数据、API 密钥、检索原文、审计交接、截图、日志、旧扩展、依赖安装目录、构建产物或原仓库 `.git`。原开发目录的历史资料保留在原位置。测试仍使用独立合成数据验证基础设施，不读取你的学习记录，也不发起在线请求。

`.gitignore` 是日常防误提交措施，不能替代打包清单与发布检查，也不会自动移除已经跟踪的文件。不要直接把原开发目录整体拖入公开仓库。发布前检查生成包的内容，并在新目录解压后执行 `npm ci`、`npm run verify:study`，确认内置题库、讲解和空题库两种情况均可启动。保留根目录 [MIT 许可证](../LICENSE) 及 [第三方声明](../THIRD_PARTY_NOTICES.md)；内置题库是模拟练习材料，非官方真题；链接到的外部资料仍遵循各自版权和使用条件。

网页检索仅由用户主动触发，服务商可能有余额、额度与速率限制；不保证永久免费或无人值守。当前公开版本不开放模型生成调用。

## 维护检查

```sh
npm run verify:study
```

该入口包含独立测试数据的格式检查、后端与前端回归、类型检查和生产构建，不依赖开发者的真实题库或个人数据。测试使用临时目录与模拟响应，不读取正式学习数据，不调用在线模型。Windows 启停集成检查需要本机 PowerShell。

原开发目录中的旧版操作、审计与验收资料只作为本机历史保留，不进入公开包。新安装和发布以本文件及根 README 为准。
