# 内置题库与通用讲解

本目录公开两个数据文件：

- `questions.json`：2000 道原创模拟题，包含选项、标准答案、题库原解析及参考链接。
- `prepared-explanations.json`：按题号、完整题目指纹和标准答案对应的通用讲解，只读加载；本机已有匹配讲解优先。

首次启动即可练习和阅读，不需要 API Key。题目为模拟练习材料，非官方真题；通用讲解不等于经过外部标准认证的答案。外部链接不改变原资料的版权。

可按 [导入说明](../README.md#题库导入) 替换自己的题库。替换内置文件需 `--replace`，旧题库先备份；更换题干或标准后，不匹配的旧讲解会停用。不要把私人题库、学习记录或抓取原文提交到仓库；Git 忽略不能保护已经跟踪的文件。

发布器只允许上述两个 JSON，其他本地文件、来源归档与备份保持私有。
